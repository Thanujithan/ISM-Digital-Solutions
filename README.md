# ISM Digital Solutions — Premium Visual Upgrade (Phase 1.5)

This upgrades the Phase 1 single-page website to more closely reflect the approved neon-green glassmorphism and foliage/ribbon concept.

## Quick start (Windows / VS Code)

1. Extract the ZIP into a folder.
2. Open the folder in VS Code.
3. Terminal: `npm install`
4. Terminal: `npm run dev`
5. Open the address displayed by Vite (usually http://localhost:5173).

For an existing Phase 1 project: replace `src/App.jsx` and `src/index.css`, copy the entire `public/assets/` folder, and leave your other files in place.

## Design fidelity
The approved mockup is an AI-generated visual reference, not a source Figma file. This project recreates the core appearance with real HTML/CSS and extracted illustrations. Real interactive content remains independently editable. Foliage is an SVG asset. The hero image and other design concept assets were cropped from the mockups created in the same conversation. Animation uses CSS; no expensive 3D engine is required. This is an improved visual match, not a claimed pixel-perfect reproduction.
